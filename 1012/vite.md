安裝vite
npm.cmd install -D vite

檢查目前專案有沒有安裝 Vite
npm.cmd list vite
有安裝vite@8.3.4
沒安裝(empty)

啟動 Vite
在package.json的scripts裡輸入"dev": "vite"

永久改善 PowerShell 的 npm 問題（選擇性）
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

如何停止 Vite？
在 VS Code 終端機按下：
Ctrl + C
下次要啟動時，再輸入：
npm run dev
