# 每日任務與日記總覽頁面：樣式規格

這一頁有四個部分，我們會**由上往下、一步一步**完成：

1. 頁首與導覽列（HEADER / NAV）
2. 每日任務
3. 日記總覽（卡片牆）
4. 回到最上面按鈕

開始之前：

- HTML 已經寫好了（`1008-practice.html`），這次只要寫 CSS。
- 先引入 `reset.css`，再寫你自己的 CSS。
- 字型用瀏覽器預設字型，不用另外設定。
- 下面的 `rem` 都以 16px 為基準。
- 每一步最後都有「✅ 完成後檢查」，做完一步先打開瀏覽器確認，再進下一步。

## 步驟 1：全站基本設定

先把整頁共用的設定做好，後面每一區都會用到。

| 項目 | 規格 |
| --- | --- |
| 盒模型 | 所有元素 `border-box` |
| 捲動 | `html` 平滑捲動（`scroll-behavior: smooth`） |
| 頁面背景色 | `#FAF8F3`（米白） |
| 內文文字色 | `#2A2B28` |
| 行高 | `1.7` |
| 連結 | 不要底線，文字顏色 `#2A2B28` |
| 圖片 | 最大寬度 `100%`，`display: block` |
| `h2`、`h3` 外距 | 上、左、右 `0`，下 `.5em` |

> 💡 `h2`、`h3` 的外距可以寫在同一條規則裡：`h2, h3 { ... }`

✅ **完成後檢查**：整頁背景變成米白色，連結沒有底線。

## 步驟 3：頁首與導覽列（HEADER / NAV）

### 結構

```
header.site-header（頁首，滿版）
└─ div.header-inner（內容容器）
   ├─ a.logo（左邊：Logo）
   │  ├─ span.logo-mark（紅色小圓點）
   │  └─ 「隨筆手帳」文字
   └─ nav.main-nav（右邊：導覽列）
      └─ ul
         └─ li > a（每個連結）
```

### 3-1 頁首外框（`.site-header`）

頁首要**黏在畫面最上方**，往下捲的時候也不會消失。

| 項目 | 規格 |
| --- | --- |
| 定位 | `sticky`，黏在距離頂端 `0` 的地方 |
| 疊放順序 | `z-index: 50`（要蓋在內容上面） |
| 背景 | 半透明米白 `rgba(250,248,243,.92)` |
| 下框線 | `1px` 實線，顏色 `#DEDACB` |

### 3-2 頁首內容容器（`.header-inner`）

Logo 在左、導覽列在右，用 **flex** 排。

| 項目 | 規格 |
| --- | --- |
| 最大寬度 | `1040px` |
| 水平置中 | 是 |
| 內距 | 上下 `16px`，左右 `24px` |
| 排列方式 | `flex` |
| 垂直對齊 | 置中 |
| 水平分布 | 兩端貼齊兩邊 |

### 3-3 Logo（`.logo`）

| 項目 | 規格 |
| --- | --- |
| 字重 | `700`（粗體） |
| 字級 | `1.3rem`（20.8px） |
| 顏色 | `#232D5C`（深藍） |
| 排列方式 | `flex` |
| 垂直對齊 | 以文字基線對齊（`baseline`） |
| 圓點與文字的間距 | `8px` |

**紅色小圓點（`.logo .logo-mark`）**

| 項目 | 規格 |
| --- | --- |
| 顯示方式 | 想一下（`span` 要設定寬高，必須先改成這個） |
| 寬、高 | 都是 `10px` |
| 背景色 | `#C1443C`（紅） |
| 圓角 | 變成圓形 |

### 3-4 導覽列

**清單（`.main-nav ul`）**

| 項目 | 規格 |
| --- | --- |
| 排列方式 | `flex`（讓連結橫向排列） |
| 連結之間的間距 | `2px` |

> 💡 清單前面的圓點 `reset.css` 已經拿掉了，不用另外設定。

**連結（`.main-nav a`）**

| 項目 | 規格 |
| --- | --- |
| 顯示方式 | 區塊元素（這樣內距才會撐開可點擊的範圍） |
| 內距 | 上下 `8px`，左右 `16px` |
| 字級 | `.92rem`（約 14.7px） |
| 字重 | `500` |
| 顏色 | `#767065`（灰） |
| 定位 | 相對定位（給下面的紅線當定位基準） |
| 滑鼠移上去（hover） | 文字顏色變成 `#2A2B28`（深色） |

**連結下方的紅線（`.main-nav a::after`）**

用偽元素 `::after` 在每個連結下方畫一條紅線。

| 項目 | 規格 |
| --- | --- |
| 內容 | 重要！（偽元素一定要有這行才會出現） |
| 定位 | 絕對定位 |
| 位置 | 距離左邊 `16px`、右邊 `16px`、下面 `4px` |
| 高度 | `2px` |
| 背景色 | `#C1443C`（紅） |

> 💡 左右各留 `16px`，剛好和連結的左右內距一樣，所以紅線會跟文字一樣寬。

✅ **完成後檢查**：

- Logo 在左、兩個連結在右，而且垂直置中。
- 每個連結文字下方都有一條紅線。
- 往下捲動時，頁首一直黏在最上面。
- 點「每日任務」「日記總覽」會平滑捲到該區塊。

## 步驟 4：每日任務

### 結構

```
form.task-form
├─ ul.task-list（任務清單）
│  └─ li.task-item（每一項任務）× 4
│     ├─ input[type="checkbox"]（勾選框）
│     ├─ label（任務名稱）
│     └─ span.tag（優先度標籤）
└─ div.add-task（新增任務列）
   ├─ input[type="text"]（輸入任務）
   ├─ input[type="date"]（日期）
   └─ button（新增按鈕）
```

### 4-1 任務清單外框（`.task-list`）

| 項目 | 規格 |
| --- | --- |
| 背景色 | `#fff`（白） |
| 框線 | `1px` 實線，顏色 `#DEDACB` |

### 4-2 每一項任務（`.task-item`）

勾選框、任務名稱、標籤排成**一橫排**，用 flex。

| 項目 | 規格 |
| --- | --- |
| 排列方式 | `flex` |
| 垂直對齊 | 置中 |
| 項目之間的間距 | `14px` |
| 內距 | 上下 `14px`，左右 `18px` |
| 下框線 | `1px` 實線，顏色 `#DEDACB` |
| **最後一項** | **不要下框線**（用 `:last-child`），不然會和外框的線疊在一起 |

### 4-3 勾選框（`.task-item input[type="checkbox"]`）

| 項目 | 規格 |
| --- | --- |
| 寬、高 | 都是 `18px` |
| 勾選後的顏色 | `#5F7F5A`（不要相信直覺） |
| 不要被壓縮 | 提示三選一：`flex-grow / flex-shrink / flex-basis` |

### 4-4 任務名稱（`.task-item label`）

| 項目 | 規格 |
| --- | --- |
| 寬度 | 佔滿剩下的空間（`flex: 1`），這樣標籤會被推到最右邊 |
| 字級 | `.95rem`（15.2px） |

**打勾之後的任務名稱**

勾選框被勾起來時，**緊接在它後面的 label** 要變成「已完成」的樣子。

| 項目 | 規格 |
| --- | --- |
| 選擇器提示 | 選隔壁鄰居 |
| 顏色 | `#767065`（灰） |
| 文字裝飾 | 刪除線（line-through`） |


### 4-5 優先度標籤

**所有標籤共用（`.tag`）**

| 項目 | 規格 |
| --- | --- |
| 字級 | `.72rem`（約 11.5px） |
| 字重 | `700`（粗體） |
| 內距 | 上下 `3px`，左右 `10px` |
| 圓角 | `100px`（變成膠囊形） |
| 不換行 | `white-space: nowrap` |

**各優先度的顏色**

| class | 背景色 | 文字色 |
| --- | --- | --- |
| `.tag-high`（高優先） | `#FBE7E4`（淡紅） | `#C1443C`（紅） |
| `.tag-mid`（中優先） | `#F6E9D2`（淡黃） | `#C98A2A`（芥末黃） |
| `.tag-low`（低優先） | `#E4EBE1`（淡綠） | `#5F7F5A`（綠） |

### 4-6 新增任務列（`.add-task`）

**外層**

| 項目 | 規格 |
| --- | --- |
| 排列方式 | `flex` |
| 項目之間的間距 | `10px` |
| 上外距 | `16px` |

**文字輸入框（`.add-task input[type="text"]`）**

| 項目 | 規格 |
| --- | --- |
| 寬度 | 佔滿剩下的空間（上面有提示過囉～） |

**輸入框和按鈕共用（`.add-task input`、`.add-task button`）**

| 項目 | 規格 |
| --- | --- |
| 字級 | `.9rem`（14.4px） |
| 內距 | 上下 `10px`，左右 `14px` |
| 框線 | `1px` 實線，顏色 `#DEDACB` |
| 圓角 | `4px` |
| 背景色 | `#fff`（白） |

**按鈕（`.add-task button`）**

按鈕要寫在共用規則的**後面**，才能蓋過上面的白底。

| 項目 | 規格 |

✅ **完成後檢查**：

- 每一項任務的勾選框、名稱、標籤排成一橫排，標籤靠最右邊。
- 最後一項任務下面沒有多一條線。
- 勾選任一項，名稱會變灰並加上刪除線；取消勾選就恢復。
- 新增任務列：文字框最寬，日期和按鈕在右邊。

## 步驟 5：日記總覽（flex 卡片牆）

### 結構

```
div.card-list（卡片牆）
└─ article.diary-card（每張卡片）× 4
   ├─ img.thumb（縮圖）
   └─ div.card-body（卡片內文）
      ├─ span.date（日期）
      ├─ h3（標題）
      └─ p（摘要）
```

### 5-1 卡片牆（`.card-list`）

| 項目 | 規格 |
| --- | --- |
| 排列方式 | `flex` |
| 換行 | 放不下時自動換行 |
| 卡片之間的間距 | `20px` |

### 5-2 每張卡片（`.diary-card`）

| 項目 | 規格 |
| --- | --- |
| 彈性寬度 | `flex: 1 1 230px` |
| 背景色 | `#fff`（白） |
| 框線 | `1px` 實線，顏色 `#DEDACB` |
| 超出範圍 | 隱藏 |

> 💡 `flex: 1 1 230px` 拆開來看：
>
> | 值 | 意思 |
> | --- | --- |
> | 第 1 個 `1`（grow） | 有多的空間時，卡片可以**變寬**去分 |
> | 第 2 個 `1`（shrink） | 空間不夠時，卡片可以**變窄** |
> | `230px`（basis） | 每張卡片的**基本寬度** |
>
> 所以畫面夠寬時一排放 4 張，變窄時會自動變成 2 張、1 張。

### 5-3 縮圖（`.diary-card .thumb`）

| 項目 | 規格 |
| --- | --- |
| 寬度 | `100%` |
| 高度 | `140px` |
| 下框線 | `1px` 實線，顏色 `#DEDACB` |

### 5-4 卡片內文（`.diary-card .card-body`）

| 項目 | 規格 |
| --- | --- |
| 內距 | 上 `16px`，左右 `18px`，下 `20px` |

**日期（`.diary-card .date`）**

| 項目 | 規格 |
| --- | --- |
| 字級 | `.72rem`（約 11.5px） |
| 顏色 | `#C1443C`（紅） |
| 字重 | `700`（粗體） |
| 字距 | `.05em` |

**標題（`.diary-card h3`）**

| 項目 | 規格 |
| --- | --- |
| 字級 | `1.05rem`（16.8px） |
| 外距 | 上 `6px`，左右 `0`，下 `8px` |

**摘要（`.diary-card p`）**

| 項目 | 規格 |
| --- | --- |
| 字級 | `.85rem`（13.6px） |
| 顏色 | `#767065`（灰） |
| 外距 | `0` |

✅ **完成後檢查**：

- 視窗夠寬時，4 張卡片排成一排，寬度一樣。
- 把視窗慢慢拉窄，卡片會自動換行（4 → 2 → 1 張一排）。
- 每張卡片的縮圖高度都一樣是 140px。

## 步驟 6：回到最上面按鈕

### 結構

```
a.back-to-top（href="#top"，連到 body 的 id）
```

按鈕要**固定在畫面右下角**，不管捲到哪裡都看得到。

| 項目 | 規格 |
| --- | --- |
| 定位 | 想一下 |
| 位置 | 距離右邊 `26px`、下面 `26px` |
| 寬、高 | 都是 `44px` |
| 圓角 | `50%`（變成圓形） |
| 背景色 | `#33417C`（藍） |
| 文字色 | `#fff`（白） |
| 箭頭置中 | 用 flex，水平、垂直都置中 |
| 字級 | `1.1rem`（17.6px） |
| 疊放順序 | `z-index: 60`（要比頁首的 `50` 大，才會蓋在最上面） |
| 滑鼠移上去（hover） | 背景色變成 `#C1443C`（紅） |

> 💡 讓一個東西在框框裡「正中間」的 flex 三件套：
> `display: flex` + `align-items: center` + `justify-content: center`

✅ **完成後檢查**：

- 往下捲動，按鈕一直停在右下角。
- 箭頭在圓形的正中間。
- 點按鈕會平滑捲回最上面。
